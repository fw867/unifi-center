说明

本应用把局域网里路由器上的软件中心（UniFi SoftCenter / KoolCenter 等插件中心） 经 NAS 转发到飞牛 fnOS 的桌面入口：在 fnOS 里就能装插件、看日志、改定时任务， 不需要给路由器做端口映射。

软件中心页面里的 Vue / Tailwind / Lucide 已换成本地副本，页面里对 GitHub 的直连也改走 NAS 转发，因此在只能访问 NAS 域名、访问不了外网的环境里同样能正常显示。

转发时按三条规则决定 Authorization：客户端自己带的真实令牌原样透传； 控制台那一跳塞的占位值 Bearer console-loopback 换成本应用保存的令牌； 完全没带凭据时也用保存的令牌顶上（都没保存才不带，让软件中心照实报 401）。
